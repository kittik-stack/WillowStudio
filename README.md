# WillowStudio – Интернет-магазин плетёных изделий из ивы

## Описание

WillowStudio – это полноценный интернет-магазин с каталогом товаров, корзиной, админ-панелью и системой заказов. Проект написан на **Node.js + Express** с использованием **MySQL** для хранения данных, **EJS** для рендеринга страниц и **сессий** для управления корзиной и авторизацией.

---

## Технологии

- Node.js + Express
- MySQL (mysql2/promise)
- EJS (шаблонизатор)
- express-session (авторизация и корзина)
- dotenv (конфигурация)
- HTML5, CSS3 (с адаптивной вёрсткой под мобильные устройства)
